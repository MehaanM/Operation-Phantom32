## CI Budget Enforcement

The CI build matrix enforces:
- **RAM ≤ 85%** on all 13 board builds (enforced — build fails)
- **Flash ≤ 90%** on LITE builds, **≤ 96%** on PSRAM builds (enforced — build fails)
- **Line coverage ≥ 85%** (enforced)
- **Branch coverage ≥ 65%** (enforced; GCC-15-calibrated — equivalent to ≥ 70% on GCC 11/12; see note below)

PSRAM builds (`doom_wrover`, `doom_s3*`) include all 13 analytics modules and legitimately use more flash; 96% is their documented ceiling. Current worst-case PSRAM board: `doom_wrover` at ~95.7%.

> **GCC 15 branch-count note**: Ubuntu 26 runners use GCC 15, which tracks additional MCDC/decision coverage data not generated by GCC 11/12. This inflates the branch count by ~16%, reducing the coverage percentage for identical tests. The 65% CI threshold is calibrated for GCC 15; local measurement on GCC 11/12 shows ≥ 70% branch coverage for the same test suite.

Current worst-case LITE board: `doom` (ESP32-WROOM-32D) at 85.0% flash.
