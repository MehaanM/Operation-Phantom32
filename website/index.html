How to flash

// three steps · ~60 seconds total

01
Use the right browser

Web flashing needs the Web Serial API — only available in Google Chrome or Microsoft Edge on desktop. Firefox, Safari, and mobile browsers will not work.

02
Connect your ESP32 via USB

Use a data-capable USB cable (charge-only cables won't work). For ESP32-S3 / C3 boards, use the UART port, not the native USB port, for flashing.

// TIP — Some boards need you to hold BOOT while clicking Flash, then release once "Erasing…" appears. NodeMCU and generic WROOM boards often require this.
03
Pick your board and flash

Go to the Flash tab, find your board (LITE if no PSRAM, PSRAM build if it has 8 MB PSRAM). Click ⚡ Flash, approve the Chrome serial port picker, and wait 20–40 seconds. Three partitions are written automatically: bootloader, partition table, and app firmware.

// AFTER FLASH — Press RST or replug. Phantom32 boots its own WiFi AP within seconds. Connect to it and open 192.168.4.1 in a browser.
04
Connect and configure

Connect to the Phantom32 WiFi network, open 192.168.4.1, and log in. From the dashboard you can configure all 13 modules, set channels, and manage everything wirelessly — no cable needed after the initial flash.

About me

I'm Mehaan Minocha, a student at Eagle Ridge Middle School who builds embedded security tools in my free time. Operation Phantom32 started as a project to understand how WiFi and Bluetooth work at a low level — and grew into something much bigger.

I designed and wrote every part of this project myself — with Claude helping me polish the implementation and troubleshoot tricky bugs — from the auth manager and rate limiter to the CI pipeline that enforces 85% test coverage across all 13 supported boards.

What is Operation Phantom32

Operation Phantom32 is a WiFi and Bluetooth security research toolkit for ESP32 microcontrollers. It runs on a $5–$15 chip, requires no PC once flashed, and gives you a full web dashboard over its own WiFi access point. Built for education, security research, and authorized network testing.

The firmware supports 81 boards across five chip families (ESP32, S3, C3), features a hardened auth system, hardware-enforced TX power safety, and ships with a full unit test suite, sanitizer runs, and SBOM generation in CI.

Why Phantom32 is different

Most ESP32 security tools are unmaintained hobby sketches with no security on the tool itself. Phantom32 is built to a professional standard from day one.
