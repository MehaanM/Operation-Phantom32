How to flash your board

Three steps. Takes about 60 seconds from start to done.

1
Use the right browser

Web flashing requires the Web Serial API, which is only available in Google Chrome or Microsoft Edge (desktop). Firefox, Safari, and mobile browsers will not work. If you are already in Chrome or Edge, you're good — move on to step 2.

2
Connect your ESP32 via USB

Plug your board into your computer with a data-capable USB cable (charge-only cables will not work). Most boards will be detected automatically. If you are on a newer ESP32 (S3, C3) with native USB, use the USB port labelled UART, not the native USB port, for flashing.

Tip: Some boards (NodeMCU, generic WROOM) need you to hold the BOOT button when clicking Flash, then release it once "Erasing…" appears.
3
Pick your board and click Flash

Go to the Flash tab and find your exact board — LITE if it doesn't have PSRAM, PSRAM build if it does. Click ⚡ Flash [Board Name], approve the serial port picker that Chrome shows, and wait. The installer downloads the firmware and writes three partitions (bootloader, partition table, app). The whole process takes 20–40 seconds.

After flashing: Press the RST (reset) button on your board or unplug and replug. Phantom32 will boot and start its own WiFi access point within a few seconds.
4
Connect and configure

On your phone or laptop, connect to the WiFi network Phantom32. Open a browser and go to 192.168.4.1. Log in with the default credentials (see your board's first boot output on a serial monitor for the generated password). From the dashboard you can configure all 13 modules, set channels, and manage everything wirelessly.

About me

I'm Mehaan Minocha, a student at Eagle Ridge Middle School who builds embedded security tools in my free time. Operation Phantom32 started as a personal project to understand how WiFi and Bluetooth work at a low level — and turned into something much bigger.

I designed, wrote, and tested every line of code in this project myself — with Claude helping me polish the implementation and troubleshoot tricky bugs — from the auth manager and rate limiter to the CI pipeline that enforces 85% test coverage across all 13 supported boards.

What is Operation Phantom32

Operation Phantom32 is a WiFi and Bluetooth security research toolkit for ESP32 microcontrollers. It runs entirely on a $5–$15 chip, requires no PC once flashed, and gives you a full web dashboard over its own access point. It's built for education, security research, and authorized network testing.

The firmware supports 13 different ESP32 boards across three chip families (ESP32, S3, C3), has a hardened auth system, a hardware-enforced transmit-power safety cap, and ships with a full unit test suite and sanitizer runs in CI.

Why Phantom32 is different

Most ESP32 security tools are unmaintained hobby sketches with no security on the tool itself. Phantom32 is built to a professional standard from day one.
