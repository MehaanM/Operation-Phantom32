◈ Requires Google Chrome or Microsoft Edge with Web Serial API support. Firefox is not supported. Connect your ESP32 via USB before clicking Flash. Firmware files are served from GitHub Releases — a release must be published for flashing to work.

How it works

01 — Connect

Plug your ESP32 into your computer via USB. Hold BOOT if your board requires it for flashing.

02 — Select board

Pick your exact board from the list below. LITE builds suit most boards; PSRAM builds unlock all 13 analytics modules.

03 — Flash

Click Flash, approve the serial port, and wait ~30 seconds. The page handles download and write automatically.
